Politique de confidentialité

En vigueur à compter du 19 octobre 2026

L’app Snowfold ne collecte aucune donnée. Il n’y a ni compte, ni outil d’analyse, ni publicité, ni pistage. Tout ce que vous créez reste sur votre appareil.

Notre site web est le seul endroit par lequel quoi que ce soit nous parvient, et uniquement lorsque quelqu’un en ouvre une page dans un navigateur web. Voir « Liens de puzzle et notre site web » ci-dessous.

Ce qui reste sur votre appareil

  • Votre progression, vos étoiles, votre série, vos créations enregistrées et toute feuille que vous avez commencé à découper.
  • Vos réglages, comme la difficulté, le son et la disposition, et le fait que la version complète soit déverrouillée ou non (pour que l’app s’ouvre déverrouillée avant même que l’App Store ait répondu).
  • Le peu de données dont le widget de l’écran d’accueil a besoin (le puzzle du jour et votre série), partagées entre l’app et son widget sur le même appareil.

Rien de tout cela n’est envoyé, ni à nous ni à qui que ce soit d’autre. Supprimer l’app supprime aussi ces données.

Achats

La version complète est un achat intégré unique, entièrement géré par Apple via l’App Store. Nous ne recevons ni votre nom, ni votre compte Apple, ni vos informations de paiement, ni votre historique d’achats ; l’app apprend seulement d’Apple si la version complète est déverrouillée sur votre appareil.

Réseau et iCloud

Snowfold n’effectue aucune requête réseau de sa propre initiative et n’utilise pas iCloud. L’app ne communique avec Internet que lorsqu’elle demande à l’App Store le prix de la version complète ou vérifie votre achat, et c’est Apple qui gère cette connexion.

Les liens qui mènent hors de l’app (cette politique, la page d’assistance, les conditions d’utilisation) s’ouvrent dans votre navigateur web après qu’un adulte a répondu à une courte question. À partir de là, il s’agit d’une visite ordinaire d’un site web ; voir la section suivante.

Partage, impression et photos

Lorsque vous choisissez de partager une image, une ligne de résultat ou un code puzzle, Snowfold ouvre la feuille de partage standard d’iOS. Ce que vous envoyez, et à qui, dépend de vous ; nous ne voyons ni vos messages ni leurs destinataires. Un code puzzle et son code QR sont créés sur votre appareil et ne contiennent que les plis et les découpes d’un puzzle, rien qui vous concerne.

L’impression passe par la fenêtre d’impression standard d’iOS. Si vous choisissez « Enregistrer l’image » dans la feuille de partage, iOS vous demande une seule fois si Snowfold peut ajouter des photos à votre photothèque. Snowfold ne peut ajouter que l’image que vous avez choisie ; l’app ne lit jamais vos photos.

Snowfold ne demande aucune autre autorisation : ni appareil photo, ni micro, ni localisation, ni contacts, ni notifications.

Liens de puzzle et notre site web

Un puzzle partagé circule sous la forme d’un lien comme https://chanbenny111.github.io/snowfold/p/?c= suivi du code puzzle. Le code fait partie de l’adresse de la page elle-même (et non d’une partie située après un « # », qui reste dans le navigateur) ; ainsi, lorsque la personne à qui vous l’avez envoyé ouvre le lien dans un navigateur web, son navigateur demande cette page à notre site web, et le code parvient au serveur web avec la requête. Certaines apps de messagerie récupèrent aussi la page d’elles-mêmes pour afficher un aperçu du lien. Il en va de même pour toute autre page de notre site web, y compris celle-ci.

Comme presque tous les serveurs web, celui qui héberge notre site web conserve des journaux d’accès standard de ces requêtes : l’adresse de la page (y compris le code puzzle), l’heure, l’adresse IP d’où provient la requête, la description que le navigateur donne de lui-même (son « user agent ») et, le cas échéant, la page d’où il vient. Ces journaux sont conservés par notre hébergeur à des fins de sécurité et pour assurer le fonctionnement du site.

  • Nous ne les utilisons ni pour de l’analyse, ni pour de la publicité, ni pour du profilage, et nous ne cherchons à identifier personne.
  • Nos pages ne déposent aucun cookie, n’exécutent aucun script d’analyse ou de pistage et ne chargent rien depuis d’autres entreprises.
  • La page du puzzle se contente de lire le code dans sa propre adresse pour afficher un bouton « Ouvrir dans Snowfold » ; elle n’envoie rien nulle part.

Le code QR d’une carte de puzzle contient le même lien, si bien que le scanner avec l’app Appareil photo ouvre la même page web. Si vous préférez que rien ne parvienne à un serveur web, copiez le lien et collez-le dans le Studio de Snowfold au lieu de l’ouvrir dans un navigateur ; rien n’est envoyé dans ce cas.

Enfants

Snowfold est conçu pour être utilisé en toute sécurité par les enfants. L’app ne collecte aucune information personnelle auprès de qui que ce soit, n’affiche aucune publicité et demande à un adulte de répondre à une courte question avant tout achat, toute restauration d’achats, tout lien externe, tout partage ou toute impression. Il n’y a ni compte, ni chat, ni moyen de contacter d’autres joueurs.
