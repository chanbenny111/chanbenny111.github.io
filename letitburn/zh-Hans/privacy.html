隐私政策

最后更新：2026年10月5日

简而言之：你写下的内容永远不会被保存、不会被上传，也不会被任何人看到。我们不收集任何数据。

你写下的内容

你输入的文字和可选的“致：”一行，只在你书写期间存在于 iPhone 的内存中。燃烧开始的那一刻，它们就会被清除；用于播放动画的页面图像只会在内存中保留到你离开结束页面（以便你把这次燃烧做成视频），随后即被释放。它们从不写入磁盘，从不包含在备份中，从不通过网络发送，也从不包含在分享卡片中。当 App 进入后台时，页面会被遮盖，因此你的文字不会出现在 App 切换器中。

页面还会关闭自动改正、输入预测、键盘学习和写作工具，并且 App 不允许使用第三方键盘，因此你的文字不会进入键盘的词库，也不会进入键盘开发者的服务器。燃烧之后，无法通过“摇动以撤销”找回文字。

烧掉的照片

你也可以烧掉一张照片或截图来代替文字。照片通过系统照片选择器选取，App 只会拿到你选中的那一张——Let It Burn 无法访问你的图库。照片只保存在内存中，放到页面上烧掉后（或你离开结束页面时）即被释放。它从不被保存、上传，也不会出现在分享卡片中；App 只记录烧过照片的次数。如果你允许存储到“照片”，也只是为了让你从分享面板保存自己的视频或分享卡片。

燃烧视频

如果你在燃烧后点按“分享视频”，视频会根据页面图像和这次燃烧的时间信息（大喊模式下的音量级别和你点按的位置）在你的 iPhone 上生成。除非你打开“显示真实文字”并确认，否则视频中的文字都会被打乱；照片也会被模糊处理，除非你选择显示。声音由 App 生成，你的声音从不被录制。视频文件生成在 App 的临时文件夹中，分享面板一关闭就会被删除。Let It Burn 不会上传任何内容，视频发到哪里由你决定。

保留在你设备上的内容

为了显示你的统计数据、连续记录和小组件，App 会为每次燃烧保留一条简短的记录，且仅存储在你的设备上：

  • 燃烧的日期和时间，
  • 你选择的仪式，以及所用的提示类别（如果用了），
  • 书写前后的心情（如果你选择了），
  • 字数，以及这是否是一封未寄出的信、是否使用了大喊模式。
  • 如果你喊了，记录怒气值（0 到 100 的数字），以及是否烧掉了照片。

App 还会存储你的设置（声音、触感反馈、提醒时间等）。这些信息存储在 App 的私有容器以及小组件使用的共享 App Group 容器中。它们绝不会离开你的设备。你可以随时在“设置”>“清除统计”中删除它们，或直接删除 App。

麦克风

大喊模式是可选的。如果你开启它，会先显示一段简短说明，然后由 iOS 向你请求麦克风访问权限；App 只读取输入的当前音量大小，用来决定火焰的大小。音频从不被录制、存储或传输。你可以随时在 iOS 的“设置”App 中关闭该权限。

购买

Let It Burn Pro 是一次性的 App 内购买项目，完全由 Apple 处理。我们从不接收你的支付信息。App 会在你的设备上通过 Apple 的 StoreKit 检查你的购买状态。

通知

如果你开启晚间提醒，它会在你的设备上本地安排。不涉及任何推送服务器。

无追踪，无第三方

Let It Burn 不包含任何分析工具、广告、崩溃报告 SDK 或第三方代码。没有账户，也没有服务器。我们不会跨 App 或网站追踪你。

儿童

Let It Burn 不会在知情的情况下收集任何人的信息，包括 13 岁以下的儿童。

变更

如果本政策发生变更，我们会更新此页面及上方的日期。

本网站与支持邮箱

本网站托管在 GitHub Pages 上，不使用 Cookie，也不做任何统计分析；但 GitHub 可能出于安全目的记录访问者的 IP 地址，详见 GitHub 隐私声明。如果你给我们发支持邮件，我们会收到你的邮箱地址和邮件内容，只用于回复你。支持邮箱是一个 Gmail 账号，因此这些邮件由 Google 按其隐私政策保存。你可以随时要求我们删除。
