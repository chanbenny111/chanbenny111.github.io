隱私權政策

最後更新：2026年10月5日

簡單來說：你寫下的內容永遠不會被儲存、不會被上傳，也不會被任何人看到。我們完全不蒐集任何資料。

你寫下的內容

你輸入的文字和可選的「致：」一行，只會在你書寫期間存在於 iPhone 的記憶體中。燃燒開始的那一刻，它們就會被清除；用來播放動畫的頁面影像只會在記憶體中保留到你離開結束頁面（讓你能把這次燃燒做成影片），之後隨即釋放。它們從不寫入磁碟、從不包含在備份中、從不透過網路傳送，也從不包含在分享卡片中。當 App 進入背景時，頁面會被遮蓋，因此你的文字不會出現在 App 切換器中。

頁面也會關閉自動修正、預測輸入、鍵盤學習和書寫工具，而且 App 不允許使用第三方鍵盤，因此你的文字不會進入鍵盤的字典，也不會進入鍵盤開發者的伺服器。燃燒之後，也無法透過「搖動來還原」找回文字。

燒掉的照片

你也可以燒掉一張照片或截圖來代替文字。照片透過系統照片挑選器選取，App 只會拿到你選中的那一張——Let It Burn 無法存取你的圖庫。照片只保存在記憶體中，放到頁面上燒掉後（或你離開結束頁面時）即被釋放。它從不被儲存、上傳，也不會出現在分享卡片中；App 只記錄燒過照片的次數。如果你允許儲存到「照片」，也只是為了讓你從分享面板儲存自己的影片或分享卡片。

燃燒影片

如果你在燃燒後點一下「分享影片」，影片會根據頁面影像和這次燃燒的時間資訊（大喊模式下的音量等級和你點按的位置）在你的 iPhone 上產生。除非你開啟「顯示真實文字」並確認，否則影片中的文字都會被打亂；照片也會被模糊處理，除非你選擇顯示。聲音由 App 產生，你的聲音從不被錄製。影片檔案產生在 App 的暫存資料夾中，分享面板一關閉就會被刪除。Let It Burn 不會上傳任何內容，影片要傳到哪裡由你決定。

保留在你裝置上的內容

為了顯示你的統計資料、連續紀錄和小工具，App 會為每次燃燒保留一筆簡短的紀錄，且只儲存在你的裝置上：

  • 燃燒的日期和時間，
  • 你選擇的儀式，以及使用的提示類別（如果有使用），
  • 書寫前後的心情（如果你有選擇），
  • 字數，以及這是否是一封未寄出的信、是否使用了吶喊模式。
  • 如果你喊了，記錄怒氣值（0 到 100 的數字），以及是否燒掉了照片。

App 也會儲存你的設定（聲音、觸覺回饋、提醒時間等）。這些資訊儲存在 App 的私有容器，以及小工具使用的共用 App Group 容器中。它們絕不會離開你的裝置。你可以隨時在「設定」>「清除統計」中刪除，或直接刪除 App。

麥克風

吶喊模式是選用的。如果你開啟它，會先顯示一段簡短說明，接著 iOS 會向你要求麥克風取用權限；App 只會讀取輸入的目前音量大小，用來決定火焰的大小。音訊絕不會被錄製、儲存或傳輸。你可以隨時在 iOS 的「設定」App 中關閉取用權限。

購買

Let It Burn Pro 是一次性的 App 內購買項目，完全由 Apple 處理。我們從不會收到你的付款資訊。App 會在你的裝置上透過 Apple 的 StoreKit 檢查你的購買狀態。

通知

如果你開啟晚間提醒，它會在你的裝置上本機排程。不涉及任何推播伺服器。

不追蹤，無第三方

Let It Burn 不含任何分析工具、廣告、當機回報 SDK 或第三方程式碼。沒有帳號，也沒有伺服器。我們不會跨 App 或網站追蹤你。

兒童

Let It Burn 不會在知情的情況下蒐集任何人的資訊，包括未滿 13 歲的兒童。

變更

如果本政策有所變更，我們會更新此頁面及上方的日期。

本網站與支援信箱

本網站託管在 GitHub Pages 上，不使用 Cookie，也不做任何統計分析；但 GitHub 可能基於安全目的記錄訪客的 IP 位址，詳見 GitHub 隱私權聲明。如果你寄支援信給我們，我們會收到你的電子郵件地址與信件內容，只用於回覆你。支援信箱是一個 Gmail 帳號，因此這些郵件由 Google 依其隱私權政策保存。你可以隨時要求我們刪除。
